# Bean There Cafe

Learning project. Landing page for a made-up cafe, built with plain HTML and CSS.

## Sections

- Navbar
- Hero
- About
- Menu
- Contact / Opening Hours
- Footer

## Built With

- HTML
- CSS (with CSS variables)
- Google Fonts: Lora, Nunito
- Color Palette: https://coolors.co/palette/ede0d4-e6ccb2-ddb892-b08968-7f5539-9c6644

## How to View

Open `index.html` in a browser.
